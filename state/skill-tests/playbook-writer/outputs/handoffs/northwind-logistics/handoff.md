# Handoff
- What the system does: creates and routes tasks from Slack into the target task system so operational follow-up is visible.
- What’s included: Slack trigger, task mapping, visibility validation path, team demo.
- Day-to-day use: create a task from Slack, confirm it lands, escalate only if visibility fails.
- Ownership: Slack workspace and target system accounts remain the client’s.
- Support boundaries: feature changes are billable; break/fix on the delivered path follows the agreed support window.
